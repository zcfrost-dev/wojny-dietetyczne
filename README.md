# Wojny Dietetyczne

Publiczna wersja strony do wrzucenia na GitHub i podpięcia w Netlify.

## Co wrzucić do GitHuba

Wrzuć zawartość tego folderu, nie folder nadrzędny.

## Edycja treści

Treści edytuj lokalnie w folderze roboczym `wojny-dietetyczne` przez lokalny panel redakcyjny. Po zapisaniu i sprawdzeniu zmian trzeba ponownie przygotować/odświeżyć ten folder do GitHuba.

## Netlify

W Netlify wybierz projekt z GitHuba. Strona jest statyczna, nie wymaga build command.
